# Improvement proposals

Proposals, completed investigations and implemented improvements. Each entry
records the problem, evidence, decision, and remaining limitations.

Some entries cite local `/tmp/...` evidence. Those paths are transient artifacts: the repository
does not version them, and raw reproducibility may be unavailable after cleanup. Each entry keeps
its method, identities, metrics, and limits.

Current status, 24 October 2026: the baseline reconciliation, saved-capture replay, live 28-query
measurement, and f6 disjoint-lane implementation are complete. The f6 fix is commit `6b31381b`.
The definition-fusion inflection fallback is implemented and raises live hit@10 to 23/28. The
remaining roadmap in the priorities document is still proposed. A 25 October read-only triage of
r7, p6, r1, and f5 found no product change needed. The f5 oracle now accepts the
`src/flatc.cpp` `ParseFile` entry point, so the saved run re-scores at 27/28. The r1
bridge is now the default-on `behavior_alt_terms` flag in `9abe9006`; on the
28-query rerank-3 run it moves r1 to rank 1 with no other case change.
