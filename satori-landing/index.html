The questions worth asking before you install anything that reads your code.

Is it really free?
Yes. Satori is open source under AGPL-3.0 and costs nothing. There is no account, no sign-up, and no paid tier. The default offline runtime needs no model API key, so there is no usage bill either.
Does my code leave my machine?
Not on the default offline runtime. Embedding, storage, search, and telemetry make no network requests after installation. Optional Voyage and Milvus/Zilliz runtimes are opt-in and billed by those providers.
Will it change my repository?
No. Source access is read-only. Install adds nothing to AGENTS.md or hook files and never overwrites files it did not write.
What does install download?
The runtime and about 100 MB of local models, once, into ~/.satori/. Your agent does not download anything again on startup.
Which languages?
Symbol navigation for TypeScript, JavaScript, Python, Go, Java, C#, C++, Rust, and Scala, plus Kotlin and PHP. Around 140 languages are searchable.
How do I remove it?
satori uninstall removes client config and the shared skill. Add --purge to also delete the runtime, models, and indexes.
