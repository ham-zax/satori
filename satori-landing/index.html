What Satori does, in plain words.

AI coding agents write code fast. Their weak step is finding where to make the change. In a large project they search for a word, open whole files, and often stop reading before they reach the part that matters. Satori is the search and map service that the agent calls before it edits.

Without Satori

  • The agent searches for a keyword and gets dozens of matches.
  • It opens whole files, and they fill its working memory.
  • It reads the top of a function and edits before it sees the rest.
  • It misses the other code that depends on the old behavior.

With Satori

  • The agent asks one question in plain English.
  • It gets the function that owns the behavior, ranked near the top.
  • It reads that function from start to end, with an outline of its file.
  • It sees who calls the function before it changes it.

Think of a smart new colleague on day one who does not yet know where anything is. Satori is the colleague who has read the whole project and says: “That lives here. These places use it. Read this first.”

Built to put the owning code first.

When the right file comes back at rank seven, your agent reads six wrong files first. Satori ranks for the code that owns the behavior, then hands the agent the exact span to read.

  1. Retrieve three ways Potion embeddings, BM25, and exact symbol matches run together, so a paraphrase and an exact identifier both reach the candidates.
  2. Search the agent’s guesses The agent sends up to four likely identifiers as alt_terms. Satori searches each one as a separate pass, including a definition lookup, and fuses the results with the original question.
  3. Vote for definitions Definition fusion lifts the code that defines a named symbol above code that only mentions it.
  4. Rerank with context Up to 64 candidates go to the reranker with their role, callers, callees, and tests. LateOn runs on your CPU in parallel sessions sized to the machine. Voyage runs in the cloud.
  5. Return exact evidence The agent gets the owning span, a file outline, and qualified call paths to follow next, instead of whole files.

The questions worth asking before you install anything that reads your code.

Is it really free?
Yes. Satori is open source under AGPL-3.0 and costs nothing. There is no account, no sign-up, and no paid tier. The default offline runtime needs no model API key, so there is no usage bill either.
Does my code leave my machine?
Not on the default offline runtime. Embedding, storage, search, and telemetry make no network requests after installation. Optional Voyage reranking, Voyage embeddings, and Milvus/Zilliz are opt-in. Voyage AI, by MongoDB, gives each account 200 million free tokens per model.
Will it change my repository?
No. Source access is read-only. Install adds nothing to AGENTS.md or hook files and never overwrites files it did not write.
What does install download?
The runtime and about 100 MB of local models, once, into ~/.satori/. Your agent does not download anything again on startup.
Which languages?
Symbol navigation for TypeScript, JavaScript, Python, Go, Java, C#, C++, Rust, and Scala, plus Kotlin and PHP. Around 140 languages are searchable.
How do I remove it?
satori uninstall removes client config and the shared skill. Add --purge to also delete the runtime, models, and indexes.
